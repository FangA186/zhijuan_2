# 常用工作台首页读取失败修复

## 原因和改变

localhost:3000默认连接8000，原8000只有DeepSeek设置，没有DATABASE_URL；任务GET抛503。此前独立8001验收环境的通过不表示8000已配置。这次先备份原草稿和候选数据，再在本项目本地PG容器创建独立zhijuan_local数据库，执行003/004本地表并复制当前草稿；仅向被忽略的根.env追加DATABASE_URL，原设置保留。验收库和其他项目库没有改变。

同时将现有health/readyz区分为配置状态与运行验证：返回数据库、队列、命题和独立盲解是否配置的布尔值，runtime_verified始终false，不仅凭模型Key宣称READY。配置不足时后端创建任务直接503、不入队；前端保留配置/预览并禁用真实生成。旧版health缺generation字段也按未配置处理。

浏览器继续发现旧示例题型topics超出用户确认的总范围，导致预览失败。前端现将旧题型考点限制在已选范围内、保留有效子集；调整后清除范围确认并明确提示，重新确认后才保存/预览。没有放松后端范围校验。
