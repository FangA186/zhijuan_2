# DEV-04 变更影响

用户批准每次修Bug前检索、修后记录，并加入本地项目页与Notion。保留工作区已有未提交改动。

实现：progress/bugs 一Bug一YAML；bug_memory CLI支持关键词检索、任务回执、记录校验与Notion待同步导出/回读回执；context自动附相关Bug索引，finish检查声明的Bug任务。页面新增搜索、状态筛选、历史根因与同步状态。复发沿用原ID和事件历史。

Notion官方MCP在现有项目总览下创建修复记忆库、表格与状态看板，回填9条历史记录并全部回读；更新总览与接手指南。不是后台双向同步服务；无法认证任意Agent是否执行所有步骤。

变更未改变业务接口、生产模型、角色权限和数据库。Bug查询内容是线索，不是执行授权；不导入原始日志、试卷正文或凭据。实际验证见browser.md及本目录离线报告。历史Bug 8条按其原证据修复，缺图1条仍OPEN；没有将历史状态冒充当前产品验收。

实现中发现macOS /var 与 /private/var 路径别名使临时记录相对路径失败，已在加载器统一resolve并通过临时目录回归。Notion查询受连接限制仅支持view，本轮改用已获取view URL完成完整回读，没有绕过访问限制。
