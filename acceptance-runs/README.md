# 实际证据目录

原 acceptance/ 是用例与模板，这里才放独立运行记录。v1.4 附带的 devtools/v1_4-final/ 仅为本次开发工具/材料的离线证据，不是产品 M0—M3 或 G-MIN/G-FULL 实际签收。

每次新目录，不覆盖旧报告。仅保存授权、脱敏的最小证据；模型密钥、私有推理、非授权题面和用户数据不入仓库。CI 工件有保留期限，需长期保留的证据按项目数据策略转入受控存储，而不是把全部日志永远写进 Git。
