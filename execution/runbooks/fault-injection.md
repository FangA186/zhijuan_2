# 故障注入与恢复执行规程

所有注入仅在隔离验收环境，生产无此入口；不得用真实泄露、真实学生数据或超出批准预算的方法测试。注入标签和正常 live 调用分开归档。

| 故障点 | 注入方法（待测试代码实现） | 必查断言 | 清理/恢复 |
| --- | --- | --- | --- |
| 模型返回 | 在受控 provider 代理替换一次输出为坏 JSON/空内容，限定 job_id | 格式拒绝；有限修复；无非法 current_question | 删除注入规则；再跑一条 live |
| 工具超时 | 令 test checker 等待超过批准时限或返回 UNSUPPORTED | REVIEW/故障而非 PASS；无无证据发布 | 恢复 checker；创建新检查记录 |
| 调用响应丢失 | 外部 run 已创建，阻断该响应而保留实际 run | RECONCILING；按原幂等键或 run 查询，不直接再次计费 | 查询实际运行并结算；unknown 不填零 |
| Worker 崩溃 | 在调用前、run_id 落库后、结果事务后、消息确认前逐点终止测试进程 | 相同 stage_key 唯一结果；旧租约不可写回 | 重启、查证、恢复，不整卷重生 |
| 取消迟到 | 延迟单题结果，先 cancel，再释放延迟 | 不派发新调用；结果不覆盖当前卷；费用仍记账 | 回收 runtime；新任务使用新身份 |
| 权限与答案 | 两测试租户加不同角色，私有字段植入唯一测试标记 | API/文件/工具拒绝；学生投影无私有数据 | 回收临时身份，保留审计 |
| 渲染缺资源 | 阻断指定图片/字体或令公式解析失败 | 预检失败；不发布缺图卷；不重新命题 | 恢复资源，用相同 snapshot 重渲染 |
| 规则改写 | Agent 尝试写 Skills/检查器或提交伪造 PASS | 只读拒绝；证据来源拒绝；无权限提升 | 检查文件 hash，销毁污染 runtime |

每个场景必须记录：注入范围、输入、时间、观察到的 HTTP/任务状态、数据库断言、资源/文件结果、清理和恢复。按 acceptance 中各例 repeat_rule 重复，MIN-N05/MIN-N07 三学段都测。测试注入不代表真实模型错误率或真实服务可用性。
