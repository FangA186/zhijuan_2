# 单任务执行记录模板

任务 ID：待填。应用 commit：待填。执行人/复核人：待填。开始与结束：待填。

## 进入检查

列出全部 depends_on 的通过记录、实际环境、批准参数和 source_files。缺前置条件写 BLOCKED，不直接开始计费运行。

## 改动与执行

逐个列出实际新增/修改的文件、代码审查链接；命令要包含工作目录、必要的变量名称（不含值）、退出码、关键输出摘要。标清 LOCAL_OFFLINE、UPSTREAM_LIVE 或 APP_LIVE，注入注明 injected=true。

## 断言与证据

每条预期对照实际结果；记录 HTTP 状态、数据库断言、文件 SHA-256 与受限证据位置。不要保存模型私有推理，普通报告不含 Key 或非授权答案。

## 失败与回退

实际错误、影响、清理、恢复、重跑结果；不能仅写“优化后通过”。未覆盖项明确列出。

## 结论

NOT_STARTED / IN_PROGRESS / BLOCKED / DONE（必须有实际实现与测试证据）。该任务完成不代表阶段通过；阶段另按 G-PREP/G-BOOT/G-MIN/G-FULL 签收。
