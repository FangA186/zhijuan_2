# 决策记录

一项重要决定一个文件，编号稳定。至少记录背景、已考虑方案、选择与原因、影响范围、迁移、回归、批准状态和后续替代关系。不得虚构审批人/日期。

新决定先 PROPOSED，批准后 ACCEPTED；被替换标 SUPERSEDED 并链接后继。记录解释“为什么”，功能状态仍以 progress/features.yaml 为准。不要把完整聊天或模型私有推理作为决策文档。

本目录新增 MEM-001 是本次开发机制选择的记录，不替代 M0 产品、架构与模型接入的正式审批。
