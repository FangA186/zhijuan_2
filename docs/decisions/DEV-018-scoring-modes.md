# DEV-018：互斥评分档位与结构化答案单一来源

2026-09-25（工作开始于9月24日）。批准依据：用户要求修复多选评分档位被相加、答案字段与评分说明冲突的问题。

## 协议

ExamSpec增加可选multiple_choice_partial_score_x100，教师在配置页输入少选且无错选得分，必须非负且小于每道多选题满分。保存时显式补默认0，不从模型输出猜测2分。进入蓝图的完整spec快照与plan_hash包含此值，改变后旧计划失效。

Answer增加scoring_mode（exclusive/additive）与partial_score_x100。新版选择/判断题用exclusive且rubric为空：全对按public.score_x100，少选按教师值（单选/判断为0），错选或空答恒0。各档互斥，不累加。解答等题型用additive、partial_score_x100为0、正数rubric累加等于题分。

为兼容旧记录，未声明新规格字段的旧答案仍默认additive；原rubric正数约束未放宽。新版规格的选择题不能用additive绕过教师评分政策。无业务数据库迁移，旧检查与候选不批量重写。

## 单一答案与检查

correct_option_ids作为选择题答案唯一展示来源；评分档位描述由同一结构化字段、题分、教师少选分生成，教师卷、编辑页、导出预览共用组件。模型不再独立书写互斥档位描述。旧数据/解析中明确声明的正确选项若与该字段不一致，新增ANSWER_TEXT_CONSISTENCY FAIL，不自动选一份覆盖另一份。只检查明确选项声明，不冒充任意自然语言或数学证明。

检查器版本从5升至6；评分和答案变化改变绑定content_hash；仍保留MATH_TRUTH及同模型盲解REVIEW，不能自动审批。scoring_mode和partial_score_x100作为私有答案字段加入盲解拒绝名单，不加入学生公开题目结构。

## 历史题修订

旧第11题保留原题和答案，转为4/2/0互斥草稿；旧第13题依据数学复算补回A、统一解析，转为互斥草稿。两份v2草稿独立保存并真实盲解一致，状态REVIEW/DRAFT_NOT_APPLIED。原任务失败证据保留，不直接改数据库结果行或伪造审批。持久化题目版本化编辑入口仍未接通，不能冒充已替换旧卷。

## 验证与回退

覆盖协议兼容、非法评分边界、模型不能改教师政策、声明冲突、版本hash、盲解私有字段拒绝、公开投影，以及实际浏览器字段保存/刷新、桌面窄屏、教师卷和导出预览。真实整卷采用显式少选200；首次发现前端字段白名单遗漏后保留0分试验并修复，新增方法级往返回归。
