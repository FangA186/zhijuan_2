# DEV-019 — 审核修订与本机教师输出流

日期：2026-09-25。批准依据：用户明确要求接入审核、修正失败候选并展示接口实际流式输出。

## 行为与约束

- M2-04 接入 author → 确定性检查 → 隔离 solver → reviewer。结构/题型失败先审核再修订；正常候选也经过审核。审核只返回简短可核验意见，不签发 PASS 或发布许可。
- 后端持久事务先登记 repair_attempt（最多2），再发起新一轮。每轮新 question_revision_id；重跑确定性检查和独立盲解。最多9次角色调用/题、总截止1200秒、单次120秒，不扩充代理预算。UNKNOWN/中断不重发；旧任务不自动恢复收费。
- 候选、检查和审核意见保存在私有 run_refs 的按轮检查点。最终不合格仍FAIL，缺数学证明仍REVIEW；不重用旧审批或检查。
- Hermes 原生 events 经订阅线程进入主执行线程，再经同一任务版本围栏持久化。message.delta 原样累加，最终返回独立标识；工具只公开名称、耗时、错误标识，不转发参数/凭据。reasoning.available 和私有推理字段不采集。
- DeepSeek 严格函数输出封装开启原生 SSE：只把指定函数的 arguments 增量转换为 assistant content。仅收到完整合法对象和完成标记才结束成功；中途断开保留 UNKNOWN 记账，不重试收费请求。非流式原路径保留。
- 本机教师 activity GET/SSE 与公开任务状态分开；仅环回请求可访问，公开任务快照仍不含模型输出、参考答案或修订检查点。生产身份/租户鉴权尚未完成，不将本机限制宣称为生产权限验收。
- 快照事件正文保留上限100万字符/2000条，发生移出时明确提示；未来长期大量事件应迁移到事件表。旧任务缺失的输出不伪造回填。

## 兼容、部署与回退

无数据库迁移；使用现有JSONB快照扩展字段。原API、结果表和盲解公开输入保持兼容。新增独立审核JSON契约、预算代理挂载及 profile.streaming=true；启动环境须使用原有安全凭据来源。不能通过读取输出密钥来修复部署。

当前网页/API热更新已验证；生成容器重载因现有启动环境缺上游凭据未执行成功，Worker尚未重启以免接入新流程后调用旧代理。后续先停止无活动任务的Worker，再按原环境更新budget-proxy并重启两台Hermes/solver-entry，最后启动Worker。不可使用新账本覆盖旧费用记录。

回退：停止新任务准入，等待/取消受理任务并对账；恢复本次列明文件的修改及旧profile，使用原环境重载服务。保留现有快照和费用账本，不能清库或删除历史。
