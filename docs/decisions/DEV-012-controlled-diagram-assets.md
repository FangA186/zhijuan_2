# DEV-012：受控数学图形资产（本地首批）

日期：2026-09-24。状态：ACCEPTED（本地实现方向）；未获产品或生产验收。

## 原因与授权

教师在 23 题试卷中发现“如图”题只有 `asset_id` 和替代文字，页面显示占位框。源码允许任意资产引用，尚无画图、资产存储和解析，也未检查图是否存在。用户明确排除自动接入 GPT 生图，选择受控结构化绘图方案。

考虑过直接切换 GPT 图像模型和继续显示文字占位。前者无法可靠保证算筹根数、排列与标注和题意一致，还会新增供应商、费用及权限边界；后者会把缺图包装成完整题面。因此两者均不采用。

## 决定与范围

- 命题仍由 DeepSeek 经 Hermes 执行。作者只可输出经 schema 限定的 `diagram` 参数；受信服务生成 SVG、计算内容哈希并签发 `asset_id`。作者直接输出未经解析的 `asset_id` 时拒绝，不从替代文字猜图。
- 首批仅支持算筹纵式 1～5。其他图形保持不支持；题目如依赖未实现的图，按失败处理，不以占位文字代替。
- 本地开发资产保存在 `.runtime/assets/`，只为当前试卷的公开引用提供只读 SVG。图形缺失或哈希不符时检查失败，前端显示缺图，旧文档导出不得静默遗漏。
- 资产哈希纳入现有候选内容哈希；改变图形须产生新的检查与盲解证据。旧 `slot_022` 记录不自动修改，需在版本化重生成流程开放后单独处理。

## 影响与迁移

涉及候选 schema、命题后处理、确定性检查、当前试卷资产读取、前端预览与导出。历史任意 `asset_id` 不因这次改动变成真实图片；缺图会显式暴露。前端仍不可把结构合法、图片可读取解释为教学质量 PASS。生产所需私有对象存储、租户授权、正式 PDF/DOCX 图形预检属于后续 M1-02、M2-07，不把本地文件目录当生产方案。

## 回归与恢复

用离线样例验证 1～5 根竖棒、非法参数/伪造 ID/损坏资产被拒绝、盲解前归一化、预览可读与缺图提示、含图旧导出阻断。无需付费模型调用或数据库迁移。回滚时停止生成新的 diagram 块，已有带资产引用的候选保留原始记录；不得删除资产后声称旧题完整。

## 批准依据

用户于本次对话明确表示：“把接入gpt模型的方案排除掉，选择你说的方案”。这仅批准本地实现方向，不代表生产迁移、付费验收或教学签收。
