# question-author

本项目技能模板，须在固定 Hermes 版本与工具权限下集成验证。

## 输入
单个槽位、必要的已提供材料、学段与学科规则、允许改动范围。

## 输出
candidate.schema.json 结构；不输出 verified、审批或发布状态。

## 执行流程
1. 先设计该题要考查的目标和作答依据，再形成题面与答案。
2. 生成的短文或情境标明为原创生成，不伪称名家作品或真实引文。
3. 题干、选项、图形、答案与评分点保持同一候选版本。
4. 缺少支持事实时报告待核，不伪造资料来源。
5. 修订只能回应发现的问题；不得改变分值或范围来绕过规则。
6. 不得调用历史题目、题库、跨任务记忆或网络搜题。

## 失败与权限边界
工具不可用、输入矛盾、证据不足时明确返回错误或待复核。不得编造工具结果、扩大权限、修改规则或输出私有思维链。只提交简洁可审核依据。任务目录与工具权限由后端实施，技能文字本身不提供隔离。

## 本版执行约束

本 Skill 由 Hermes 执行，默认使用 DeepSeek；不调用或安装 LangChain、LangGraph。模型、阶段、题目版本、工具权限和修订额度来自后端批准的配置，不能由 Skill 自行扩大。角色使用同一 model_id 时标记 SAME_MODEL，不声明异构验证；无法确认时返回待复核，不变更审批与发布条件。

## 结构与分值边界

- 每次只生成输入题槽的一道题；严格保留 local_id、kind 与 score_x100。
- score_x100 是分值的百分之一整数单位：100 表示 1 分，不是 100 分。参考答案的 rubric 各项 score_x100 之和必须等于题目的 score_x100。
- 输出仅为一个可解析 JSON 对象，最外层只有 public 和 private；private.answers 必须是数组，包含当前题目对应的一个答案对象。
- 输入如提供 output_skeleton，它只规定结构，不提供题目或答案。填写所有空白文字，选择正确的稳定选项 ID，不添加题干外的回复、Markdown 围栏或自报通过字段。
- 空白文字段必须填写或删除：text 块的 text 不得是空字符串；若某一段只有公式，直接输出 math 块，不要在它前后保留空的 text 块。
- 需要 1～5 算筹纵式图时，只能在题面或选项输出 `{"type":"diagram","spec":{"kind":"counting_rods","values":[1,2,3,4,5]}}`，由受信服务按数值画图并签发 asset_id；不得自行编造 asset_id、SVG、图片 URL 或图已生成的声明。
- 其他图形类型当前不支持；不要以“如图”或 asset 占位引用冒充真实图。确实无法用文字/表格准确表达时说明不支持，由受信流程判失败，不擅自改题意。

## 评分输出契约

- 选择/判断题使用 `scoring_mode: exclusive`，`rubric: []`。全对得题目满分；错选或空答0分；多选少选分只能复制输入骨架中的 `partial_score_x100`，不能自行改变。评分说明由受信界面从结构化答案生成，不再输出另一份正确选项清单作为评分规则。
- 解答等题型使用 `scoring_mode: additive`、`partial_score_x100: 0`，rubric为可累加且为正数的采分点，合计等于题分；不得把全对、部分对、全错等互斥档位塞进rubric。
- `correct_option_ids` 是选项答案唯一字段；解析若声明正确选项，必须与该字段一致。多选题须有至少两个正确选项；不确定时不能伪造一致性。

## 本卷考点与多样性

- 以冻结slot.target_topic为本题的具体主考点；整本教材范围只提供边界，不得改成其他容易生成的考点。
- same_paper_questions仅含当前任务已生成的公开题干摘要，用于避免重复，不是历史题库。不要重复相同方程、条件组合、情境或仅替换问法/数字；遇到IN_PAPER_DIVERSITY失败应重新设计本题。
- 同一考点再次出现时遵守槽位中的差异要求；题型、分值、课程范围保持冻结值。
